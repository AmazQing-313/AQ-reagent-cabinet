# 数据格式说明

## data.json

程序把它放在 **exe 同目录**（源码运行时是 `src/` 同目录，可用环境隔离）。
写入是原子的：先写 `data.json.tmp`，再 `os.replace` 替换，断电不会写坏。

| 字段 | 类型 | 说明 |
|---|---|---|
| `app` | string | 固定 `reagent-locator`，用于识别文件 |
| `savedAt` | string | 最后一次保存时间（ISO 8601） |
| `items` | array | 材料条目，见下表 |

条目字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 程序内部唯一标识，导入时可省略（会自动生成） |
| `name` | 是 | 名称，空名称的条目会被丢弃 |
| `alias` | 否 | 别名/英文名/化学式，搜索时一并匹配，建议都写在这里 |
| `cas` | 否 | CAS 号 |
| `spec` | 否 | 规格，如 `AR 500g` |
| `category` | 否 | 类型，如 `无机盐` |
| `cabinet` | 否 | 柜号，如 `一号柜`；支持“1号柜/柜1/1”互搜 |
| `slot` | 否 | 柜内位置，如 `二层 左`；排序时识别顶/底、层数、左中右 |
| `qty` | 否 | 数量，纯文本，如 `2 瓶` |
| `note` | 否 | 备注 |
| `updatedAt` | 否 | 毫秒时间戳，用于“最近更新”排序 |

## Excel 导入

直接选 `.xlsx` / `.xlsm` 即可，程序用标准库解析（`zipfile` + `xml.etree`），不依赖 openpyxl。

列名支持这些别名（大小写、括号备注、空格都不影响）：

| 字段 | 可用的表头写法 |
|---|---|
| 名称（必需） | 名称、品名、试剂名称、材料名称、物料名称、中文名、试剂、材料、name |
| 别名 | 别名、英文名、化学式、分子式、英文、又名、alias |
| CAS | CAS号、CAS、CAS No.、CAS编号、casno |
| 规格 | 规格、型号、包装、纯度、规格型号、spec |
| 类型 | 类型、分类、类别、种类、category |
| 柜号 | 柜号、柜子、柜、存放柜、柜位 |
| 柜内位置 | 柜内位置、位置、存放位置、层、层位、具体位置、slot |
| 数量 | 数量、库存、剩余、余量、qty |
| 备注 | 备注、说明、note、remark |

- 表头可以在前 10 行的任意位置（前面有标题行也没关系）
- 多张工作表时，优先选能识别出表头的那张
- 「位置」写成 `一号柜 二层 左`，会自动拆成 `cabinet=一号柜`、`slot=二层 左`
- 旧版 `.xls` 不支持，请另存为 `.xlsx`

## CSV 导入

表头（顺序任意，按列名匹配）：

```
名称,别名,CAS号,规格,类型,柜号,位置,数量,备注
```

- 编码：UTF-8（带不带 BOM 都可以）
- 去重键：`名称 + 柜号 + 位置`；命中则更新，否则新增
- 名称为空的行会被跳过

## 备份

每次启动时，如果 `备份/` 里还没有当天的副本，会复制一份 `data-YYYYMMDD.json`。
